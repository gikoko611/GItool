# G.I TOOL

**All-in-one Android toolkit** with a dark futuristic UI, neon green/gold accents, and a custom G.I launcher icon.

## Current starter
- Android app (Java + WebView), minimum Android 6.0 (API 23)
- Searchable toolkit dashboard and category filters
- 100+ utility entries in the catalog
- Custom vector launcher icon
- GitHub Actions builds a debug APK on every push to `main` and on manual dispatch

> Important: the catalog is a starter UI. Individual utilities are being implemented progressively; a tile does not imply every tool is fully functional yet.

## Build APK
Open **Actions → Build G.I TOOL APK** and download the `GI-TOOL-debug-apk` artifact after a successful run.

## Local build
Requires JDK 17 and Gradle 8.9+; run `gradle assembleDebug`.
